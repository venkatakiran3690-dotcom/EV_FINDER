Centralized EV Hub & Geofenced Platform

Smart EV Station Finder, Geofenced Pre-Booking & Billing Management System

A robust, multi-tenant Java Spring Boot and MySQL web application for urban and highway electric vehicle infrastructure. Featuring server-side 30 km Haversine geofenced pre-booking, conflict-safe concurrency locking, simulated charging sessions, and downloadable PDF invoices.

Interactive Map & Finder Role Portals Demo
System Architecture
  • Backend: Java 21, Spring Boot 3.3, Hibernate
  • Database: MySQL 8.x (17 relational tables)
  • Geofencing: Haversine 30 km server validation
  • Booking: Overlap intervals concurrency lock
  • Billing: BigDecimal GST calculation + OpenPDF

Platform Capabilities & Core Modules

Designed for real-world EV operations with multi-company tenant isolation

Interactive Discovery & Map

Leaflet.js & OpenStreetMap integration with filters for AC/DC chargers, connector types (CCS2, Type 2, CHAdeMO), power kW, occupancy rates, and estimated queue wait time.

30 km Software Geofence

Server-side mathematical enforcement using the Haversine formula in Java. Pre-booking is verified and rejected if the vehicle is outside the 30 km radius to prevent slot hoarding.

Conflict-Safe Slot Booking

Database transaction isolation evaluating half-open intervals [existingStart, existingEnd). Zero double-booking guarantee with demo token reservation payments.

Simulated Charging Sessions

Deterministic energy delivery algorithm computing kWh based on charger power kW and elapsed time without physical IoT sensors. Live battery visualizer and state transitions.

Tariff & PDF Invoicing

Regulated CPO tariff engine with BigDecimal currency computations (Energy Cost + Service Fee + 18% GST). Downloadable authenticated PDF tax receipts powered by OpenPDF.

4 Role-Based Portals

Platform Admin, Company Admin (Tata Power, Zeon), Station Manager, and EV Driver portals with strict backend data isolation preventing cross-company data leakage.
